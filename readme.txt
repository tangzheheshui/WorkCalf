========================================
 闲牛 WorkCalf v1.0 —— 佛系打工小牛桌面桌宠
========================================

【这是什么】
一只憨厚短角棕牛悬浮在桌面上：
- 你打字/动鼠标时，它跟着一起"打工"（打字点脑袋、头看向你的鼠标、点得太快还会流汗）
- 你停下来一小会儿，它会发呆眨眼
- 闲置超过设定时长，它就蹲下来敲木鱼（哒、哒、哒……）

纯单机软件：不联网、不登录、不付费、不上传任何键鼠数据。

----------------------------------------
【Windows 使用】
1. 双击 WorkCalf.exe 即可，无需安装。
2. 小牛出现在屏幕右下角，左键按住可拖动，右键点小牛出菜单。
3. 配置文件 config.json 在 exe 同目录，可用记事本直接编辑（改完重启生效，
   或直接在"设置面板"里改，实时生效）。

----------------------------------------
【macOS 使用】★ 重要 ★
1. 首次打开若提示"无法验证开发者"：右键 .app → 打开，或到
   系统设置 → 隐私与安全性 → 仍要打开。
2. ★必须授权★：系统设置 → 隐私与安全性 → 辅助功能 →
   勾选"闲牛（WorkCalf）"。不授权则无法监听全局键鼠，
   小牛不会响应打字和鼠标（程序会弹窗引导）。
3. 配置文件位于 ~/Library/Application Support/WorkCalf/config.json

----------------------------------------
【功能速查】
- 右键小牛 / 系统托盘：音效开关、设置面板、重置位置、退出
- 设置面板：闲置时长(3/4/5/8s)、动画速度、缩放(0.5~2.0)、
  鼠标穿透、音效总开关
- 鼠标穿透开启后：点击小牛区域会穿透到后方窗口，此时无法
  拖拽小牛，也点不到它的右键菜单 —— 请用系统托盘关回穿透！

----------------------------------------
【常见问题】
Q: 关掉窗口怎么退出？
A: 本程序没有窗口标题栏，请右键小牛或托盘图标选"退出程序"。

Q: 打字没有声音？
A: 检查右键菜单/设置面板里的音效总开关。

Q: 托盘图标在哪？
A: Windows 在右下角任务栏托盘区（可能收进"^"折叠里）；
   macOS 在屏幕顶部菜单栏右侧。
