========================================
 勤劳的牛牛 WorkCalf v1.0 —— 佛系打工小牛桌面桌宠
========================================

【这是什么】
一只涂鸦风的白牛牛趴在工位上（桌面、键盘、鼠标同框，背景透明）：
- 你打字/动鼠标时，它跟着一起"打工"（视线跟着鼠标、按下的键会在它的小键盘
  上亮起来；右手会高高抬起再砸向那个键）。打字时身体和脑袋不抖动
- 整幅画面（小牛、桌面、键盘、鼠标垫）像照片一样统一斜一个小角度，
  桌面、键盘、鼠标垫的长边互相平行；
  小键盘平铺在桌上、斜着朝它自己；键帽大、黑边细，数字看得清且
  不会超出键帽。Delete/退格/回车/方向键等也会亮。
- 鼠标垫在键盘左下、靠近小牛座位的桌面上，和键盘不重叠；鼠标默认停在垫子
  正中间，按真实鼠标的位移在垫子上跟手滑动（左右、上下都按它自己的视角，
  和你的手移动方向相反），停手约 1 秒后回到垫子中央
- 键盘上没有的键（如 F1-F12）会在手边浮出小键帽，不会毫无反应
- 你停下来一小会儿，它会发呆、半眯着眼偷瞄你
- 闲置超过设定时长，它就趴下敲木鱼，还会冒烟（哒、哒、哒……）

纯单机软件：不联网、不登录、不付费、不上传任何键鼠数据。

----------------------------------------
【Windows 使用】
1. 双击 WorkCalf.exe 即可，无需安装。
2. 小牛出现在屏幕右下角，左键按住可拖动。
3. 配置文件 config.json 在 exe 同目录，可用记事本直接编辑（改完重启生效，
   或直接在"设置面板"里改，实时生效）。

----------------------------------------
【macOS 使用】★ 重要 ★
1. 首次打开若提示"无法验证开发者"：右键 .app → 打开，或到
   系统设置 → 隐私与安全性 → 仍要打开。
2. ★必须授权★：系统设置 → 隐私与安全性 → 辅助功能 →
   勾选"勤劳的牛牛（WorkCalf）"。不授权则无法监听全局键鼠，
   小牛不会响应打字和鼠标（程序会弹窗引导）。
3. 配置文件位于 ~/Library/Application Support/WorkCalf/config.json

----------------------------------------
【功能速查】
- 系统托盘（菜单栏右侧小牛图标）：左键单击/右键菜单 → 设置面板、退出程序
- 设置面板：缩放(0.3~2.0)、不透明度(0.2~1.0)、鼠标穿透、音效总开关
- 小牛窗口内任意位置都可以左键拖拽；
  鼠标停在桌宠上滚动滚轮即可缩放（每格 0.05，范围 0.3~2.0；
  往下滚缩小、往上滚放大），缩放时窗口位置保持不动
- 鼠标穿透开启后：整个窗口都会穿透到后方窗口，此时无法
  拖拽小牛，也点不到小牛 —— 请用系统托盘关回穿透！

----------------------------------------
【常见问题】
Q: 关掉窗口怎么退出？
A: 本程序没有窗口标题栏，请点菜单栏右侧托盘小牛图标选"退出程序"。

Q: 打字没有声音？
A: 检查设置面板里的音效总开关。

Q: 托盘图标在哪？
A: Windows 在右下角任务栏托盘区（可能收进"^"折叠里）；
   macOS 在屏幕顶部菜单栏右侧。
